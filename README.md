# COSC-3351-Individual-Project
Creating an HTML website using CSS and asynchronous JavaScript with APIs.

## Description
This is an HTML website created in Visual Studio Code. It has a CSS and JavaScript file linked to the HTML file. The "img" folder contains the images used on the website, like the background and horoscope icons.
"Daily Astrology" is a website that offers 3 main sections to the viewer: upcoming major astrological events, information about tonight's moon phase, and information about the viewers horoscope. "Home" takes the user back to the landing page/section. This site is mainly for those who like astrology.

## How to Run
Download all the files, place them in a same folder, and open the index.html on your device. You navigate between each section on the webpage by clicking the buttons in the navigation/under the title.

## Data Source Credits
Every API I used came from this website: https://cosmyday.com/api-docs. I used the "/events/upcoming" URL for the "Sky Events" section, the "/content/moon" URL for the "Moon Phase" section, and the "/content/daily" URL for the "Horoscope" section.
